# fixtures

`ufret-sample-sheet.json` は ufret から抽出した `ExtractedSheet` と同じ形の
**合成データ**で、実在の楽曲ではない。曲名・アーティスト名・歌詞はすべて
テスト用のダミー値で、コード進行も一般的なものを並べただけのもの。

行の構成は converter のふるまいを網羅するように組んである:

- 歌詞なし行と歌詞あり行が交互に並び、`Intro` / `Verse N` / `Interlude N` /
  `Outro` の 7 セクションに分割される
- 1 行のコード数が `{time:}` の分子より少なく、歌詞の文字数比で小節を
  埋めるケース (2:2:4 → `| F | C | G | G |`、4:3 → `| F | F | G | G |`)
- 行頭のコード無しセルが前行の最終小節に連結されるケース

**実在曲の歌詞・コード譜をフィクスチャとしてコミットしないこと。** 著作権上の
問題になるため、実サイトで動作確認した結果をそのまま貼り付けるのではなく、
必要なケースを満たす合成データをここに置く。
